# Данные расширения

Расширение не отправляет телеметрию, журналы или списки файлов своему разработчику.
Сеть используется страницей Яндекс Диска и расширением для получения файла
или картинки с доменов Яндекса, на которых размещён открытый пользователем материал.

Локально в Firefox сохраняются:

- последняя введённая ссылка и настройки подпапки/PNG;
- идентификаторы успешных загрузок, локальные имена и отметка о сохранении превью;
- последние сообщения журнала и ошибка открытия панели.
- очередь публичных ссылок, выбранная пауза и настройки восстановления;
- полный журнал текущей очереди, сохраняемый по блокам, и идентификатор её сеанса.

Кнопки «Сохранить полный журнал» и «Диагностика» создают локальные файлы по просьбе пользователя.
Полный журнал содержит ссылки очереди, имена файлов и сообщения об ошибках.
Он не входит в пакет расширения и не загружается в репозиторий. Перед отправкой
журнала другому человеку проверьте личные данные в нём.
Диагностика содержит адрес страницы, имена карточек, классы элементов и подписи кнопок.
Перед публикацией такого отчёта проверьте, какие данные в нём содержатся.

Для загрузок браузер может использовать существующие cookies Яндекса. Расширение
не получает пароли и не запрашивает токены доступа. Сохранённая публичная ссылка
не публикуется в GitHub и не передаётся разработчику.

В Firefox сборка заявляет `data_collection_permissions: none`:
данные не собираются и не передаются разработчику для удалённого хранения или обработки.
