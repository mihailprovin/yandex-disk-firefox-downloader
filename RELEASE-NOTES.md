## 1.1.1

- Тайм-аут старта и отсутствия прогресса сокращён с 5 до 3 секунд. Пауза между файлами — 1 секунда.
- Пакет собирается только из семи явно разрешённых файлов расширения.
- Добавлена автоматическая проверка публикуемых исходников на личные пути, email, секреты и реальные ссылки Диска.

Публичная сборка расширения Firefox для последовательного скачивания Яндекс Диска.

- Ссылка задаётся пользователем; личные тестовые архивы в сборку не включены.
- Поддерживаются публичный Диск и интерфейс общего доступа Яндекс 360.
- Нет старта/прогресса 3 секунды — отмена оригинала и сохранение PNG из просмотра для изображений.
- Между файлами сохраняется секундная пауза.
- Добавлены воспроизводимая сборка ZIP/XPI, тесты и GitHub Actions.

Пакеты **не подписаны Mozilla**. Установка: `about:debugging` → загрузить временное
дополнение → выбрать XPI. После перезапуска Firefox загрузите дополнение снова.

Проверки выполнены на синтетической странице и модели Firefox API.
Совместимость с реальной текущей разметкой Яндекса требует проверки пользователем.
