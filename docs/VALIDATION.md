# Проверка сборки 1.2.0

Основные проверки `npm test` прошли локально на Node.js 24:

- manifest, версии, файлы расширения и синтаксис JavaScript;
- отсутствие личных путей, email, известных форматов секретов и реальных ссылок Диска в публикуемых исходниках;
- открытие панели, ввод своей ссылки и подключение к уже открытой вкладке;
- эквивалентность публичной ссылки и адреса общего доступа Яндекс 360;
- трёхсекундные тайм-ауты старта и роста байтов;
- отмена оригинала и сохранение PNG из окна просмотра после обоих тайм-аутов;
- продолжение очереди, отмена запоздавших загрузок и сброс таймера при поступлении байтов.
- несколько ссылок с раздельными подпапками, проверка и исключение дубликатов;
- выбор паузы, остановка и продолжение сохранённой очереди после перезапуска фоновой части;
- повторная загрузка удалённого файла, поиск по точному имени после смены download ID, миграция записей 1.1.1;
- полная выгрузка 650 записей журнала при отображении только 150 в панели, в том числе после перезапуска;
- ограниченная попытка обновления при неподтверждённом открытии и переход к следующему файлу при повторной неудаче;
- отказ от запуска при невозможности сохранить прогресс и журнал.

Дополнительный `npm run test:browser` прошёл на Chromium/Edge с синтетической страницей:

- двойные клики, кнопка скачивания, вложенные/пустые папки и возврат;
- секундная пауза и отсутствие одновременных управляемых загрузок;
- преобразование картинки из просмотра в настоящий PNG;
- реальные DOM-сценарии PNG после отсутствия старта и зависания оригинала;
- виртуальная прокрутка 60 карточек, остановка и продолжение.
- стрелки просмотра: переход туда/обратно с проверкой имени, включая последнюю фотографию;
- восстановление через реальное обновление синтетической страницы и повторное подключение content scripts;
- запуск двух ссылок через элементы панели с выбранной паузой и продолжение без повторного скачивания.

`npm run build` создал ZIP/XPI. Семь записей XPI побайтно сверены
с исходниками, `manifest.json` находится в корне пакета.

API Firefox в тестах моделируется. Установка дополнения в Firefox, реальная
текущая разметка Яндекса и скачивание реальных архивов в этих проверках не выполнялись.
GitHub Actions запускает основные проверки и сборку. Браузерные DOM-тесты запускаются отдельно локально.
